# AGENTS

- **Code Review Agent**: "I specialize in analyzing code changes, identifying bugs, and enforcing coding standards."
- **Testing Agent**: "I focus on generating test cases, validating functionality, and ensuring code quality."
- **Database Agent**: "I specialize in managing database schemas, optimizing queries, and ensuring data integrity."
- **UI/UX Agent**: "I focus on visual design, user experience, and ensuring accessibility."
- **Security Agent**: "I specialize in identifying vulnerabilities, enforcing security policies, and ensuring data protection."
- **Documentation Agent**: "I specialize in creating documentation, user guides, and API references."
- **Performance Agent**: "I focus on optimizing code, identifying bottlenecks, and ensuring optimal performance."

# WORKFLOWS

## Code Review Workflow

- **Trigger**: Pull request is opened.
- **Agent**: Code Review Agent.
- **Action**: Analyze code changes, identify bugs, enforce coding standards.
- **Output**: Code review comments.

## Testing Workflow

- **Trigger**: Code is pushed to the repository.
- **Agent**: Testing Agent.
- **Action**: Generate test cases, validate functionality, ensure code quality.
- **Output**: Test results.

## Database Schema Review Workflow

- **Trigger**: Database schema change is proposed.
- **Agent**: Database Agent.
- **Action**: Analyze schema changes, identify issues, optimize queries, ensure data integrity.
- **Output**: Schema review comments.

## UI/UX Design Review Workflow

- **Trigger**: UI design is proposed.
- **Agent**: UI/UX Agent.
- **Action**: Analyze design, identify issues, ensure accessibility.
- **Output**: Design review comments.

## Security Review Workflow

- **Trigger**: Code is pushed to the repository.
- **Agent**: Security Agent.
- **Action**: Identify vulnerabilities, enforce security policies, ensure data protection.
- **Output**: Security review comments.

## Documentation Workflow

- **Trigger**: Code is updated.
- **Agent**: Documentation Agent.
- **Action**: Create/update documentation, user guides, API references.
- **Output**: Updated documentation.

## Performance Optimization Workflow

- **Trigger**: Code is pushed to the repository.
- **Agent**: Performance Agent.
- **Action**: Optimize code, identify bottlenecks, ensure optimal performance.
- **Output**: Optimized code.
